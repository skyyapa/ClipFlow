# ClipFlow MVP 与路线图

## 当前状态

ClipFlow 0.11.0 已完成可运行的 Windows 原型。它能够长期驻留后台，记录文本、图片和文件列表，并通过全局快捷键完成搜索与粘贴。

## 已完成：基础原型

- WPF 应用壳、系统托盘和单实例运行
- Windows 剪贴板格式监听
- 文本、HTML、RTF 和图片捕获
- QQ/微信截图兼容处理
- 相同文本与图片自动去重
- SQLite 历史持久化、FTS5 全文索引与 PNG 图片存储
- 旧版 XML 历史自动迁移和备份
- Windows 文件/文件夹列表捕获、搜索和再次粘贴
- 文件关联图标、打开项目和资源管理器定位
- 独立轨道的鼠标可拖动滚动条
- 单页设置窗口、开机自启和自定义快捷键
- 可配置历史容量、图片保留天数和图片空间上限
- 文字卡片纯文本粘贴按钮与双击即粘即走
- `Ctrl + Shift + V` 全局呼出
- 搜索、键盘导航和自动粘贴
- 原格式粘贴与纯文本粘贴
- 收藏、删除、清空未收藏记录
- 暂停与恢复监听
- 多显示器、负坐标和 Per-Monitor V2 高 DPI 定位
- Windows 11 风格紧凑浮窗、圆角搜索框和细滚动指示器

## 已验证

- 源码可使用项目构建脚本生成 `dist\ClipFlow.exe`
- 程序可启动并持续后台运行
- 外部复制文字可写入持久化历史
- 模拟截图可保存为 PNG 并再次粘贴
- 窗口可拖动，并能定位到当前屏幕任务栏上方
- 125%、150%、200% 缩放使用 Per-Monitor V2 清单

## 下一阶段：日常可用性

优先级从高到低：

1. 连续粘贴队列
2. 多行文本转 TSV 的表格预览
3. 来源应用筛选、应用排除与敏感内容规则
4. 历史导入、导出和备份

## 后续阶段：性能与管理

- 为搜索加入来源应用和内容类型过滤器
- [x] 将图片编码和数据库写入移出 UI 线程
- 按图片磁盘占用执行清理
- 为收藏内容增加标题、标签和分组
- 增加崩溃恢复、自动升级和安装包
- 完善键盘可访问性、多语言和自动化测试

## 暂不优先

- 跨设备同步
- 在线账户
- 团队共享
- 云端 OCR
- AI 自动总结

## 下一里程碑完成标准

- 用户无需编辑配置文件即可修改快捷键与容量
- [x] 能筛选、清理并重新定位失效文件路径
- 连续粘贴可完成常见表单录入
- 大量历史记录下搜索和启动没有明显停顿
- 后续升级不会丢失现有 SQLite 历史和图片
