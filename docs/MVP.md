# MVP 与路线图

## 阶段 0：技术验证

目标：确认 Windows 剪贴板监听、全局快捷键、焦点恢复和自动粘贴稳定可靠。

- 监听文本、HTML、图片和文件列表
- 去重并记录来源应用
- 全局快捷键呼出无边框窗口
- 选择记录后写回剪贴板
- 将焦点交还原窗口并触发粘贴
- 验证管理员窗口、远程桌面、多显示器和高 DPI 环境

完成标准：连续运行一天不丢失监听，不出现复制循环，不破坏用户原剪贴板。

## 阶段 1：可用 MVP

- 最近记录列表
- 全文搜索
- 键盘导航
- 原格式粘贴 / 纯文本粘贴
- 收藏和置顶
- 本地持久化
- 托盘菜单
- 暂停记录与一键清理
- 基础设置：快捷键、保留时间、最大条数、开机启动

完成标准：能够替代 Windows 剪贴板历史完成日常文本工作。

## 阶段 2：差异化能力

- 连续粘贴队列
- 多行文本与 TSV 表格预览
- 图片缩略图与图片搜索筛选
- 文件记录与手动归档
- 片段标题、标签和分组
- 来源应用过滤

完成标准：解决办公录入、Excel 和常用回复场景，而不增加主流程操作成本。

## 阶段 3：打磨

- 搜索排序学习用户使用频率
- 重复内容合并与版本展开
- 存储空间管理
- 导入、导出与备份
- 无障碍和多语言
- 性能、崩溃恢复和安装升级

## 首个迭代任务顺序

1. 建立应用壳、托盘和单实例运行
2. 实现剪贴板监听与去重
3. 建立 SQLite 数据模型和后台写入队列
4. 实现浮窗、全局快捷键与键盘导航
5. 实现搜索与结果虚拟化
6. 实现粘贴、纯文本粘贴和焦点恢复
7. 加入收藏、删除、暂停和设置
8. 完成高 DPI、多屏和异常应用测试
