# ClipFlow MVP 与路线图

## 当前状态

ClipFlow 0.7.6 已完成可运行的 Windows 原型。它能够长期驻留后台，记录文本和图片，并通过全局快捷键完成搜索与粘贴。

## 已完成：基础原型

- WPF 应用壳、系统托盘和单实例运行
- Windows 剪贴板格式监听
- 文本、HTML、RTF 和图片捕获
- QQ/微信截图兼容处理
- 相同文本与图片自动去重
- XML 历史持久化与 PNG 图片存储
- `Ctrl + Shift + V` 全局呼出
- 搜索、键盘导航和自动粘贴
- 原格式粘贴与纯文本粘贴
- 收藏、删除、清空未收藏记录
- 暂停与恢复监听
- 多显示器、负坐标和 Per-Monitor V2 高 DPI 定位
- Windows 11 风格紧凑浮窗、圆角搜索框和细滚动指示器

## 已验证

- 源码可使用项目构建脚本生成 `dist\ClipFlow.exe`
- 程序可启动并持续后台运行
- 外部复制文字可写入持久化历史
- 模拟截图可保存为 PNG 并再次粘贴
- 窗口可拖动，并能定位到当前屏幕任务栏上方
- 125%、150%、200% 缩放使用 Per-Monitor V2 清单

## 下一阶段：日常可用性

优先级从高到低：

1. 设置界面：快捷键、最大条数、保留天数和开机启动
2. 文件列表记录与文件名搜索
3. 连续粘贴队列
4. 多行文本转 TSV 的表格预览
5. 来源应用筛选与应用排除
6. 历史导入、导出和备份

## 后续阶段：性能与管理

- 从 XML 迁移到 SQLite
- 使用 FTS5 提升大量文本的全文搜索性能
- 按图片磁盘占用执行清理
- 为收藏内容增加标题、标签和分组
- 增加崩溃恢复、自动升级和安装包
- 完善键盘可访问性、多语言和自动化测试

## 暂不优先

- 跨设备同步
- 在线账户
- 团队共享
- 云端 OCR
- AI 自动总结

## 下一里程碑完成标准

- 用户无需编辑配置文件即可修改快捷键与容量
- 能可靠记录并搜索文件列表
- 连续粘贴可完成常见表单录入
- 大量历史记录下搜索和启动没有明显停顿
- 升级版本不会丢失现有 XML 历史和图片
