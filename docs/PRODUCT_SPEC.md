# ClipFlow 产品规格

## 1. 项目定位

Windows 自带剪贴板历史容量有限，搜索、长期保存、格式处理和内容管理能力不足。ClipFlow 不做一个需要经常打开整理的资料库，而是做一个融入复制粘贴动作的快速入口。

核心价值：

> 任何复制过的内容，都能在几秒内重新找到，并以正确格式粘贴到正确位置。

## 2. 目标用户

- 高频处理文本、表格和即时通讯的办公用户
- 程序员、设计师、运营、客服和销售
- 经常在浏览器、微信、Office、IDE 之间切换的人
- 需要反复使用代码、地址、回复模板和账号信息的人

## 3. 核心痛点与对应能力

| 痛点 | ClipFlow 能力 |
|---|---|
| 找不到几分钟前复制的内容 | 持久历史记录与即时全文搜索 |
| 网页文字带背景色和字体 | 一键纯文本粘贴 |
| 姓名、电话、地址需要逐条粘贴 | 连续粘贴队列 |
| 多行文字粘进 Excel 后结构错误 | 行列预览、分隔符识别与表格粘贴 |
| 代码和常用回复需要长期保留 | 收藏、置顶、标签和片段库 |
| 图片和文件无法统一管理 | 图片缩略图、文件列表与来源信息 |
| 剪贴板可能包含密码或隐私 | 应用排除、暂停记录、敏感内容清理 |

## 4. 主交互

### 4.1 快速搜索与粘贴

1. 用户按可配置全局快捷键。
2. 搜索浮窗出现在当前工作屏幕中央。
3. 默认展示最近记录；输入后即时过滤。
4. 上下键选择记录。
5. `Enter` 按原格式粘贴，`Shift+Enter` 以纯文本粘贴。
6. 粘贴完成后浮窗自动消失，焦点回到原应用。

### 4.2 连续粘贴

用户选择多条记录加入队列。之后每次触发“粘贴下一项”，ClipFlow 按顺序写入并粘贴，适合姓名、电话、地址或表单录入。

队列必须明确显示当前位置，并支持撤销上一步、循环与清空。

### 4.3 表格化粘贴

对于多行文本，ClipFlow 提供轻量预览：

- 自动识别换行、Tab、逗号和分号
- 选择“每行一个单元格”或“拆成行列”
- 输出标准 TSV，让 Excel、WPS 和表格软件正确分格

### 4.4 片段库

任意历史记录可收藏为片段。片段支持标题、标签和快捷搜索，但不要求用户先整理才能使用。

## 5. 内容类型

### 文本

保存纯文本、富文本摘要、来源应用、复制时间和内容哈希。搜索以纯文本为主。

### HTML / 富文本

保留原始格式，同时生成纯文本版本；用户可随时选择无格式粘贴。

### 图片

保存本地图片副本、缩略图、尺寸、格式和时间。列表优先显示缩略图，不自动进行云端识别。

### 文件

默认记录文件路径和元数据，不擅自复制大型文件。用户可将重要文件记录“归档”，归档后由 ClipFlow 保存副本。

## 6. 搜索与排序

默认排序综合考虑：

1. 关键词匹配度
2. 最近使用时间
3. 使用次数
4. 收藏与置顶状态

搜索范围包括正文、片段标题、标签、文件名和来源应用。首个版本不依赖复杂语法，后续可增加 `type:image`、`app:chrome` 等过滤器。

## 7. 隐私与安全

- 所有数据默认只存本机
- 支持暂停记录 5 分钟、30 分钟或直到手动恢复
- 支持排除指定应用
- 可设置历史保留天数、最大条数和图片空间上限
- 支持一键清空未收藏历史
- 数据库中只保存必要元数据
- 密码自动识别只能作为辅助，不能替代应用排除与暂停机制

## 8. 非目标

首个版本不做：

- 跨设备同步
- 团队共享知识库
- 在线账户体系
- AI 自动总结或云端 OCR
- 复杂的文档管理和版本控制

这些能力会增加信任成本和产品重量，与“呼出即用，用完即走”的初始目标冲突。

## 9. 成功指标

- 呼出浮窗后，常用内容在 3 秒内完成粘贴
- 10,000 条文本记录下搜索仍无明显等待
- 捕获新剪贴板内容不干扰当前应用
- 普通桌面环境中呼出到可输入的感知延迟低于 200ms
- 用户无需打开管理页面，也能完成绝大多数操作
