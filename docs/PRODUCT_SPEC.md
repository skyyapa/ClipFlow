# ClipFlow 产品规格

本文描述 ClipFlow 0.14.0 原型版的产品定位、当前能力和后续方向。标记为“规划”的内容尚未实现。

## 1. 项目定位

Windows 自带剪贴板历史容量有限，缺少搜索、长期保存和灵活管理能力。ClipFlow 的目标不是成为需要频繁整理的资料库，而是成为复制粘贴流程中的快速入口。

> 任何复制过的内容，都能快速找到，并以需要的格式粘贴回当前应用。

## 2. 目标用户

- 经常在浏览器、微信、Office 和 IDE 之间复制内容的用户
- 需要找回历史文字或截图的办公用户
- 经常复用代码、地址和回复模板的程序员、运营、客服与销售
- 希望剪贴板数据保留在本机的用户

## 3. 当前能力

| 场景 | 0.14.0 支持情况 |
| --- | --- |
| 找回之前复制的文字 | 已支持持久历史与关键词搜索 |
| 去除网页字体和背景格式 | 已支持纯文本粘贴 |
| 长期保存常用内容 | 已支持收藏，收藏内容不自动清理 |
| 管理 QQ、微信和普通截图 | 已支持缩略图、去重和再次粘贴 |
| 连续粘贴姓名、电话、地址 | 已支持临时顺序队列与快捷键逐条粘贴 |
| 将多行文字拆分到 Excel 单元格 | 已支持 TSV/HTML 表格预览与粘贴 |
| 记录复制的文件和文件夹 | 已支持路径列表、文件名搜索和再次粘贴 |
| 排除指定应用或自动识别密码 | 已支持应用排除和可选的本地敏感单行文本规则 |

## 4. 核心交互

### 4.1 呼出与搜索

1. ClipFlow 在系统托盘后台运行。
2. 用户按 `Ctrl + Shift + V`。
3. 窗口出现在鼠标所在屏幕的右下角、任务栏工作区上方。
4. 搜索框自动获得焦点；空搜索显示最近记录，输入后即时过滤。
5. 界面一次最多展示 100 条结果。

### 4.2 选择与粘贴

- `↑` / `↓`：选择记录
- `Enter`：按原格式粘贴
- `Shift + Enter`：以纯文本粘贴
- `Ctrl + S`：收藏或取消收藏
- `Delete`：删除当前记录
- `Esc`：隐藏窗口

粘贴时，ClipFlow 将内容写回系统剪贴板、隐藏窗口、恢复此前的前台窗口并发送粘贴按键。

### 4.3 鼠标操作

- 单击卡片选择内容
- 使用卡片右侧按钮收藏或删除
- 按住顶部空白区域拖动窗口
- 滚轮按像素滚动，标准一格约移动 20px
- 双击卡片直接粘贴并隐藏窗口
- 文字卡片右侧的 `A` 按钮以纯文本粘贴
- 文字卡片右侧的 `+` 按钮加入连续粘贴队列
- 多行文字卡片右侧的 `▦` 按钮打开表格预览

### 4.4 连续粘贴与表格

连续粘贴队列保持用户加入时的顺序和重复项。点击开始后自动粘贴第一条，之后全局呼出快捷键临时变为“粘贴下一条”；队列完成后自动恢复普通呼出行为。失败不会推进队列，队列可从托盘取消。

多行文字可按自动或手动分隔方式转换为二维表格。最终剪贴板同时包含 CRLF/Tab 文本和 HTML 表格；“保留为文本”默认开启，以保护电话号码、前导零、长数字和公式样内容。转换不修改原历史记录。

### 4.5 设置

从系统托盘的“设置…”打开单页设置窗口，可配置：

- 开机自动启动
- 呼出快捷键组合与按键
- 最大历史条数（50 至 50,000）
- 图片保留天数（0 表示不按日期清理）
- 未收藏图片空间上限（10MB 至 10GB）

新快捷键被占用时会自动恢复旧快捷键。

## 5. 内容类型

### 文本与富文本

保存 Unicode 纯文本，并在剪贴板提供时同时保留 HTML 和 RTF。搜索基于纯文本和来源应用名称。

### 图片

支持 WPF Bitmap、PNG 流、PNG 字节及常见 Bitmap 数据。图片统一转换为 PNG 保存，并使用 SHA-256 去重。QQ/微信截图可能携带无效 Alpha 通道，ClipFlow 会转换为 Bgr32 以确保可见。

### 文件

保存 Windows `FileDrop` 中的路径列表，不复制原文件。文件卡片显示首个有效项目的关联图标、名称和项目数量；可重新写回 `FileDrop`，也可打开首个有效项目或在资源管理器中定位。文件被移动或删除后会显示完全或部分失效状态，并可集中筛选、清理或重新定位路径。

## 6. 排序、去重与容量

- 空搜索按“收藏优先、最近复制优先”排序
- 多个搜索词采用全部匹配规则，不区分大小写
- 相同文本合并为一条，并更新复制时间和次数
- 相同图片按内容哈希合并
- 默认最多保留 5,000 条普通记录
- 超出容量时优先删除最早的未收藏记录
- 收藏内容不会被容量清理，因此总数可能超过 5,000 条

## 7. 数据与隐私

- 所有数据默认仅保存在本机
- 不需要账户，不上传剪贴板内容
- 支持从托盘暂停或恢复记录
- 支持清空全部未收藏记录
- 历史数据库位于 `%LocalAppData%\ClipFlow\clipflow.db`
- 图片位于 `%LocalAppData%\ClipFlow\images`
- 旧版 `history.xml` 会自动导入，导入后保留为 `history.xml.migrated-backup`
- 可通过 `CLIPFLOW_DATA_DIR` 环境变量覆盖数据目录

用户可按来源进程筛选历史；设置页可排除指定进程，并可选择跳过疑似验证码、银行卡号和高复杂度密码。敏感识别为本地启发式规则，默认关闭，不作为密码保险箱的替代方案。

图片清理只处理未收藏图片。超过保留天数的未收藏图片会删除；超过空间上限时从最早的未收藏图片开始清理。收藏图片始终保留，因此实际目录可能超过设置的空间上限。

## 8. 产品边界

当前不计划优先实现：

- 跨设备云同步
- 团队共享知识库
- 在线账户体系
- 云端 OCR 或 AI 自动处理
- 复杂文档管理与版本控制

这些能力会增加隐私和使用成本，不符合“呼出即用，用完即走”的核心方向。

## 9. 质量目标

- 复制行为不被 ClipFlow 阻塞
- 剪贴板暂时被占用时进行有限次数重试
- 自己写回剪贴板的内容不重复入库
- 多显示器和常见 DPI 缩放下窗口位置正确
- 图片缺失或读取失败时给出明确状态，不导致程序崩溃
- 连续粘贴严格串行，失败时不丢失或跳过当前条目
- 表格预览可以截断显示，但实际粘贴内容不得截断
