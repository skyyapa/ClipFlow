# 粘贴板管理器

产品名：**ClipFlow**  
一句话定位：**剪贴板领域的 Everything——呼出即用，用完即走。**

ClipFlow 是一款 Windows 本地剪贴板管理器。它持续记录文本、富文本、图片和文件，支持瞬时搜索、纯文本粘贴、连续粘贴、表格化处理与长期片段收藏。

## 当前可运行版本

第一版 Windows 原型已完成，可直接双击 `start-clipflow.cmd` 启动。程序启动后常驻系统托盘，不显示主窗口。

- 按 `Ctrl + Shift + V` 呼出
- 输入关键词即时搜索
- `↑` / `↓` 选择记录
- `Enter` 保留格式粘贴
- `Shift + Enter` 纯文本粘贴
- `Ctrl + S` 收藏或取消收藏
- `Delete` 删除记录
- `Esc` 隐藏窗口
- 托盘菜单可暂停记录、清空未收藏历史或退出

历史数据保存在 `%LocalAppData%\ClipFlow\history.xml`，关闭或重启后仍会保留。

当前原型已经支持文本、HTML/RTF 格式、QQ/微信截图与普通剪贴板图片、搜索、收藏、删除和持久化。文件列表、连续粘贴和表格转换将在后续迭代加入。

图片会转换为 PNG 保存到 `%LocalAppData%\ClipFlow\images`。相同截图只保留一份，并直接显示在历史内容卡片中；不再提供独立的大图预览区。选择图片后按 `Enter` 可粘贴回当前应用。

### 构建

运行 `build.ps1` 会使用 Windows 自带编译器生成 `dist\ClipFlow.exe`，当前不需要额外安装开发环境。

## 核心体验

1. 用户复制任何内容，ClipFlow 在后台安静记录。
2. 按全局快捷键呼出搜索框，直接输入关键词。
3. 方向键选择，回车粘贴，窗口立即消失。
4. 不需要整理，也不打断当前工作流。

## 产品原则

- **零打断**：主流程只需“呼出、搜索、粘贴”。
- **键盘优先**：所有高频操作都能在不碰鼠标的情况下完成。
- **本地优先**：默认不上传剪贴板内容，不依赖账户或网络。
- **格式可控**：保留原格式和纯文本粘贴同等容易。
- **搜索优先于分类**：先让用户找得到，再提供收藏与分组。
- **敏感内容可退出**：支持暂停记录、应用排除和自动清理。

## 首个版本

- 文本、HTML、图片、文件列表的历史记录
- 全文即时搜索
- 普通粘贴与纯文本粘贴
- 收藏、置顶、标签与常用片段
- 连续粘贴队列
- 多行文本转行列后粘贴到 Excel
- 重启后保留，可配置保留时间和数量
- 托盘运行、快捷键呼出、隐私暂停
